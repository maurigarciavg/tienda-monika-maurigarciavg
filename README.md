# 🧶 Tienda de Crochet de Monika
Proyecto Full Stack para la venta de productos artesanales hechos a mano.

## 🛠️ Tecnologías utilizadas
* **Backend:** Node.js y Express
* **Frontend:** HTML5, CSS3 y JavaScript Vanilla
* **Estado:** Cimientos y estructura básica completada.

## 🚀 Cómo ejecutarlo
1. `npm install`
2. `node server.js`
3. Abrir `http://localhost:3000`
